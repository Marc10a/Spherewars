SPHEREWARS: OTRO MUNDO - como verla en tu ordenador

1. Instala Node.js 20 o superior (https://nodejs.org, version LTS).
2. Descomprime el zip en una carpeta.
3. Haz doble clic en "iniciar.bat" (Windows).
   - La primera vez instala dependencias (necesita internet, unos minutos).
   - Cuando termine, abre http://localhost:3000 en el navegador.

A mano (Windows, Mac o Linux), dentro de la carpeta:
   npm install
   npm run build
   npm start
   -> http://localhost:3000

Notas
- No hace falta Supabase para verla: sin configurar, el panel /admin avisa de que falta y las secciones dinamicas
  (catalogo comercial, eventos, descargas) muestran estados vacios. La wiki, las facciones y las fotos funcionan.
- Mas detalles: docs/SETUP.md
